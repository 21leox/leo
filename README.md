# Leo'nun Kişisel Web Sitesi

Bu proje, Next.js ve Tailwind CSS kullanılarak geliştirilmiş kişisel bir web sitesidir.

## Teknolojiler

- Next.js 14
- React
- Tailwind CSS
- TypeScript

## Özellikler

- Responsive tasarım
- Koyu tema
- Proje galerisi
- İletişim formu
- Belgeler bölümü

## Kurulum

1. Projeyi klonlayın:
```bash
git clone [repo-url]
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

4. Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.
